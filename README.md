# Gemini Chat Exporter 🤖→📄

Расширение для Google Chrome (**Manifest V3**), которое экспортирует ваши диалоги с **Google Gemini AI** в чисто оформленные Markdown (`.md`) файлы — как один текущий чат, так и **все чаты сразу в ZIP-архив**.

---

## ✨ Возможности

- **Один клик** — мгновенный экспорт открытого разговора в `.md` файл.
- **Массовый экспорт в ZIP (`v1.1.0`)** — пакетная выгрузка нескольких или всех чатов из истории в единый `.zip` архив с помощью встроенного `zip_writer.js` (без внешних зависимостей).
- **Умный парсер DOM** — 4 каскадные стратегии поиска сообщений, устойчивые к обновлениям вёрстки Gemini.
- **Полный Markdown** — сохранение заголовков, блоков кода с подсветкой языка, таблиц, списков, цитат и ссылок.
- **Предпросмотр и буфер обмена** — просмотр итогового Markdown прямо в окне расширения и быстрое копирование без сохранения файла.
- **100% локально и приватно** — все данные обрабатываются исключительно в браузере.
- **Тёмный UI** — минималистичный интерфейс в едином стиле.

## 🚀 Установка (Developer Mode)

1. Склонируйте репозиторий или скачайте папку расширения:
   ```bash
   git clone https://github.com/dvd-bolt/export.git
   ```
2. Откройте Chrome и перейдите по адресу: `chrome://extensions/`
3. Включите **«Режим разработчика»** (правый верхний угол).
4. Нажмите **«Загрузить распакованное расширение»**.
5. Выберите папку проекта.
6. Иконка расширения появится в панели браузера.

---

## 📖 Использование

1. Перейдите на [gemini.google.com](https://gemini.google.com) и откройте нужный чат.
2. Нажмите на иконку **Gemini Chat Exporter** в панели расширений Chrome.
3. Выберите действие:
   - **«Экспортировать чат»** — скачать текущий диалог в `.md`.
   - **«Скопировать MD»** — скопировать разметку в буфер обмена.
   - **Пакетный экспорт** — выгрузить выбранные чаты одним `.zip` архивом.

## 📁 Структура файлов

```text
export/
├── manifest.json       # Конфигурация расширения (Manifest V3, v1.1.0)
├── background.js       # Service Worker: координация вкладок и пакетного экспорта
├── content.js          # Скрипт парсинга DOM чата и конвертации в Markdown
├── zip_writer.js       # Встроенный генератор ZIP-архивов в памяти браузера
├── popup.html          # UI всплывающего окна
├── popup.css           # Стилизация интерфейса (Dark UI)
├── popup.js            # Логика попапа, предпросмотра и управления экспортом
├── generate_icons.py   # Python-утилита для генерации иконок
└── icons/              # Иконки расширения (16, 32, 48, 128 px)
```

## ⚙️ Технические детали

Парсер использует **4 стратегии** для поиска сообщений:

1. **Custom Elements** — теги `<user-query>` и `<model-response>` Gemini.
2. **Атрибуты ролей** — селекторы `[data-message-author-role]`.
3. **DOM-эвристика** — анализ структуры вложенности и классов контейнеров.
4. **Широкий резервный поиск** — паттерны `[class*="message"]`, `[class*="response"]` и др.

---

## 🔒 Приватность

- **Никаких серверов** — всё обрабатывается локально внутри вашего браузера.
- **Минимальные разрешения** — `activeTab`, `scripting`, `downloads`, `storage`, `tabs` только для домена `https://gemini.google.com/*`.
- **Нет телеметрии** — расширение не собирает и никуда не отправляет аналитику.
